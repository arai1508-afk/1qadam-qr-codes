## 💡 Жүйенің Негізгі Артықшылықтары мен Функциялары

### 1. 🚀 Жылдам Өту (Quick Navigation)
Мұғалімдер мен оқушылар смартфон камерасын QR-кодқа бағыттау арқылы платформадағы белгіленген сабаққа немесе тестке бір секундта өте алады.

### 2. 📚 Интерактивті Сабақ Модульдері
- 🧮 **Математикалық логика:** Есептер мен квиздерге сілтемелер.
- 🔬 **STEM тапсырмалар:** Инженерлік және ғылыми интерактивті модельдер.
- 🏆 **Нәтиже тақтасы:** Оқушылардың рейтингін анықтау.

### 3. 🖨️ Баспа Материалдарына Арналған
Бұл QR-кодтар оқулықтарға, жұмыс дәптерлеріне және мектеп стендтеріне басып шығаруға толықтай бейімделген (HD форматында).

## 🛠️ Қолданылуы (Usage)
1. Қажетті QR-код файлын `qr_codes/` папкасынан таңдаңыз.
2. Смартфонмен немесе кез келген QR-сканер арқылы сканерлеңіз.
3. 1Qadam интерактивті білім жүйесіне өтіп, тапсырмаларды орындаңыз!
